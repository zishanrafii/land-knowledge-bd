# Phase 1 Foundation — কাজের অবস্থা

## তৈরি করা হয়েছে
- Next.js App Router + TypeScript ভিত্তি
- Tailwind CSS ও Land Knowledge BD color tokens
- বাংলা/English toggle-সহ responsive homepage
- Light/Dark theme toggle (homepage state)
- Search input ও `/laws?q=` handoff
- Firebase client initialization
- Initial Firestore and Storage security rules
- Firestore index definition
- PWA manifest
- Environment variable template
- Setup ও deployment README

## এখনো করা হয়নি
- npm install / dependency resolution
- TypeScript, lint ও production build run
- Firebase project connect বা live rules deploy
- Authentication ও trusted admin provisioning
- Firestore-backed search ও legal record pages
- Admin/reviewer workflow
- Netlify deployment
- Automated tests

## গুরুত্বপূর্ণ সতর্কতা
এই পরিবেশে build/test চালানো হয়নি। তাই এটিকে build-successful বা production-ready বলা হচ্ছে না। কোনো বাস্তব আইন বা আদালতের রায় demo হিসেবে seed করা হয়নি।
